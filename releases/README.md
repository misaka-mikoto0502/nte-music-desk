# 本地发布产物

2.x 代码统一更新 `release/2.0.0`，每次正式小版本通过独立标签和发布附件保留快照；新大版本才建立新分支。

本地保留基线与正式版本产物，各版本目录互不覆盖；Source 源码包为整理后的仓库内容，不含个人数据、模型或构建环境。

当前为 2.0.2，整合完整离线转谱、CPU 提速、后台演奏、曲目管理和迷你播放器换曲。Windows 便携包、Source 源码包及各自 SHA-256 位于 v2.0.2/，同目录有发布正文、集中校验表和验证报告。更新说明见 docs/RELEASE_NOTES_2.0.2.md；验证见 docs/VALIDATION_2.0.2.md；上传步骤见 docs/PUBLISH_2.0.2.md。开发入口位于 .build/current/异环演奏工作台/；按使用者要求，另在 v2.0.2/异环演奏工作台/ 保留完整可运行归档，供拍摄和测试，后续开发与普通清理均保留。

v2.0.1/ 保留已发布的界面与易用性版本，不覆盖；其说明与验证文档仍使用原文件名。

初始本地 2.0.1 检查点已迁入私有归档，并保留 archive/v2.0.1-initial-20261108 标签。当前 v2.0.1 对应最终发布提交。该初始包、开发预览包及 .build 中验证包均不作为本次 GitHub 附件。

2.0.0 包继续保留于 v2.0.0/，对应发布记录为 docs/RELEASE_NOTES_2.0.0.md 和 docs/VALIDATION_2.0.md。版本提交和标签在本地保存，公开 GitHub 发布单独处理。

v1.5.0/NTE-Music-Desk-v1.5.0-Windows-x64.zip 及同名旧标签是此前检查点，继续保留供回退。2.0 不覆盖旧版本，构建工具也默认拒绝覆盖同名 ZIP。1.5 开发记录与旧包路径仅作为历史参考。

1.3.0 音频转谱为可选独立引擎，需要另行安装、接受模型许可与登录；便携包不附带模型。原曲谱导入与游戏演奏无需安装 Python。

仅本说明进入 Git；其他构建产物由 .gitignore 排除。GitHub Release 可上传 Windows x64 ZIP 与校验文件，源码仓库请上传项目文件或 Source 包内容。
