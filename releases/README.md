# 本地发布产物

本地保留基线与正式版本产物，各版本目录互不覆盖；Source 源码包为整理后的仓库内容，不含个人数据、模型或构建环境。

当前 1.5 仍在开发，暂不作为最终版上传。v1.5.0/NTE-Music-Desk-v1.5.0-Windows-x64.zip 及同名本地标签是此前的检查点，保留供回退；后续源码会继续修改，不移动旧标签或覆盖旧包。最终发布前统一确定版号、重建源码包与 Windows 包并重新校验。当前待办见 docs/NEXT_STEPS.md。

1.5.0 新增启动时提权、迷你播放器及 F7 暂停/继续，鼠标操作悬浮窗建议无边框全屏。沿用 1.4.0 的本地导入、伴奏转谱和独立旋律 Beta。音频识别需可选引擎与模型条款确认，原唱自动分离暂缓开放。发布内容见 docs/RELEASE_NOTES_1.5.0.md。

1.3.0 音频转谱为可选独立引擎，需要另行安装、接受模型许可与登录；便携包不附带模型。原曲谱导入与游戏演奏无需安装 Python。

仅本说明进入 Git；其他构建产物由 .gitignore 排除。GitHub Release 可上传 Windows x64 ZIP 与校验文件，源码仓库请上传项目文件或 Source 包内容。
