# 本地发布产物

本地保留基线与正式版本产物，各版本目录互不覆盖；Source 源码包为整理后的仓库内容，不含个人数据、模型或构建环境。

当前版本为 2.0.1，收录布局、四种基础色、控件与引导改进。Windows 便携包、Source 源码包和两份 SHA-256 位于 v2.0.1/。更新说明见 docs/RELEASE_NOTES_2.0.1.md；软件检查与人工待验收项见 docs/VALIDATION_2.0.1.md。请完整解压新的 ZIP 到新目录运行，旧解压目录不代表本轮构建。

2.0.0 包继续保留于 v2.0.0/，对应发布记录为 docs/RELEASE_NOTES_2.0.0.md 和 docs/VALIDATION_2.0.md。版本提交和标签在本地保存，公开 GitHub 发布单独处理。

v1.5.0/NTE-Music-Desk-v1.5.0-Windows-x64.zip 及同名旧标签是此前检查点，继续保留供回退。2.0 不覆盖旧版本，构建工具也默认拒绝覆盖同名 ZIP。1.5 开发记录与旧包路径仅作为历史参考。

1.3.0 音频转谱为可选独立引擎，需要另行安装、接受模型许可与登录；便携包不附带模型。原曲谱导入与游戏演奏无需安装 Python。
