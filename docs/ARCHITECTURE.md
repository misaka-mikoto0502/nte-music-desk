# 项目结构

```text
nte-music-desk/
├── src/nte_music_desk/
│   ├── _bootstrap.py       # 源码与 EXE 共同入口
│   ├── cli.py              # 命令行、演奏调度、合成试听与子进程
│   ├── ui.py               # 主窗口
│   ├── startup.py          # 图形应用启动时提权，离线命令不提权
│   ├── mini_player.py      # 置顶、不激活的迷你播放器
│   ├── playback.py         # 暂停时钟、控制序号与按键恢复
│   ├── appearance.py       # Pillow 圆角、可调浓度背景与原生按钮皮肤
│   ├── midi.py             # 标准 MIDI 读取、节奏与音域转换
│   ├── performance.py      # 统一按键时序与计划发声音符
│   ├── presets.py          # 按曲谱哈希与乐器保存方案
│   ├── segments.py         # 原曲时间输入解析
│   ├── analysis.py         # 移调候选与适配报告
│   ├── parts.py            # GM 乐器、稳定声部拆分与角色提示
│   ├── track_ui.py         # 共用声部表、多轨工作区与音符总览
│   ├── arranging.py        # 声部八度与旋律/低音优先保留
│   ├── transcription.py    # 可选 MuScriptor 子进程与结果校验
│   ├── audio_ui.py         # 引擎配置、安装、转谱与取消界面
│   ├── audio_audition.py   # MCI WAV 同位置对照、定位、暂停和循环
│   ├── audio_quality.py    # 已知 MIDI 参考的一对一起音/音高评估
│   ├── audio_pipeline.py   # 本地选段、伴奏与独立旋律 Beta 流程
│   ├── melody.py           # GAME 权重确认/校验与旋律结果转换
│   ├── rights.py           # 用户来源说明与逐模型条款检查
│   ├── notation.py         # MusicXML/MXL、KAR/RMI 统一导入
│   ├── instruments.py      # 乐器键位表
│   ├── keyboard.py         # 前台核对、按键及 UAC 启动
│   ├── local_library.py    # 只读旧版本地曲名，不含网络访问
│   ├── paths.py            # 资源与用户数据目录
│   ├── diagnostics.py      # 不发送按键的离线发布自检
│   └── assets/             # 图标、帮助、示例 MIDI
├── tests/                  # 自包含离线测试，不使用个人曲谱
├── tools/                  # EXE 构建与版本元信息
├── docs/                   # 使用、结构与发布说明
├── .github/workflows/      # Windows 自动构建
└── releases/               # 本地发布产物，Git 忽略二进制
```

图形应用在创建 Tk 窗口前请求一次 UAC，取消则退出；演奏子进程使用已有管理员令牌普通启动。离线分析、转换、自检和版本命令不提权。源码 GUI 采用 -I 保留已安装的 Pillow；游戏按键子进程使用 -I/-S 与可信 bootstrap，冻结时直接调用 EXE。重启后仍未获得权限会报错退出，不循环弹 UAC。

1.3.1 的 Pillow 仅用于界面绘制，核心转换和演奏调度继续使用标准库。圆角按钮继承原生 Tk Button，保留焦点、空格触发与禁用语义。背景为包内清理过 UID 的图片，运行时对背景区降低饱和度、叠加遮罩；窗口和文字不做全局透明。背景浓度独立保存在个人设置中，不进入曲目方案。图片缺失时界面回退为纯色。构建环境、CI 和源码启动显式安装依赖；提权演奏子进程继续保持原有隔离参数。

调度使用一个单调时钟，重复键先松再按，异常与取消后释放自己持有的键。窗口标题、HTGame.exe、窗口进程和前台焦点均被核对。钢琴仅允许程序持有的左 Shift，人工按下的其他修饰键会中止；混合黑白和弦以快速分组适应全局 Shift 状态。

只读资源与写入目录分开：资源来自包内 assets（EXE 中为 _internal 下的包资源），写入默认位于 %LOCALAPPDATA%\NteMusicDesk。可用 --data-dir 或 NTE_MUSIC_DESK_DATA_DIR 覆盖数据目录，方便离线测试与个人备份。

在线搜索、下载模块与目录快照已移除；界面和命令行只读取主动选择的本地音乐文件。旧版 downloaded_midis 来源侧车仅用于恢复曲名，不访问外部地址。MXL 在内存中校验并读取，拒绝重复、越界、过大或加密的文件；MusicXML 不解析实体或访问外部 DTD。

所有导入最终生成同一 MidiSong 时间化音符模型，复用选轨、演奏与试听。另存 MIDI 以固定速度网格编码秒级音符时刻，面向互通和演奏，不作为保真制谱文档导出。

转换谱保留来源音轨、原曲时间及有限的变更明细。performance_plan 一次生成物理按键事件、计划发声音符和总时长，供键盘执行、时序试听与报告使用；原谱对照另从 MidiSong 合成。音色与游戏输入是否接收仍需实机核对。移调分析和试听在后台执行，过期结果按任务 token 丢弃；停止试听与改变参数会取消合成，开始游戏前取消推荐结果。

演奏方案文件以内容 SHA-256 和乐器命名，带独立 schema；保存前验证设置、曲谱转换与调度。不会把个人绝对路径存入方案，也不把默认用户数据写到源码或内置资源中。

1.3.0 的 MidiSong 将原轨/通道/程序变化拆成稳定虚拟声部，part_sources 保留旧轨映射。方案 v2 保存角色与和弦音数，v1 选择扩展到对应新声部并备份；读取失败的方案不会自动覆盖。批量恢复选轨避免反复绘制。

faithful/balanced 模式保留独立起音，整体八度选择后再处理残余越界，先合并同音再按角色减音。软件每组音数与实际按住键峰值分别报告；钢琴同色音可重叠，遇修饰键切换或重复键提前释放。指标基于计划，不测量游戏声音。

轻量入口由 light_audio.py 启动仅绑定 127.0.0.1 的标准库 HTTP 服务，随机会话路径、资源白名单、严格 Host/Origin 和有界消息；浏览器在本机 Worker 中使用 Basic Pitch / TensorFlow.js CPU，按窗口释放 Tensor，只向桌面传回音符和来源记录。主线程消息队列完成导入，忙碌时阻止启动游戏演奏；过期任务不能发布结果。随包资源约 1.51 MB，包含官方小模型、JS 和许可，无 Node/Python 音频环境；模型输出仍为 Beta。

高级音频引擎在独立环境或指定的外部 Python 中执行；冻结 EXE 不作为开发环境。MuScriptor 处理已有伴奏，GAME 为独立歌声 Beta。任务在子进程中解码选段、识别并校验 MIDI，保留原曲选段偏移；取消终止本任务及其后代，取消后的消息不自动导入。源码与便携包不含高级引擎的 PyTorch / ONNX 运行时或大权重。

rights.py 在识别前要求素材使用说明及当前受限模型条款确认，记录为用户说明而非已核验授权。换文件清空素材说明及旧结果。GAME 的下载和缓存使用都检查确认项；分离只允许 UMX-HQ，ViperX 在父流程与 worker 均拒绝调用。separation_runtime.py 获取并校验四份官方 MIT 权重，以 weights_only 加载；20 秒窗口交叉淡化，输出共同增益及相同帧数的伴奏和人声。日志遮盖 HF 令牌，任务目录仍含音频与私人说明，应由用户自行保管。

音频试听准备只解码最多 30 秒，使用独立子进程。对照试听先在后台渲染选中 MIDI 的轻量合成音，再用 Windows MCI waveaudio 按共同毫秒位置切换音源，不控制游戏；开始新任务、输入变更或游戏演奏时关闭。使用 Windows 已有短路径兼容旧 waveaudio 驱动，不修改文件名或系统设置。模型访问检查只有用户主动点击时才请求授权文件元数据，不把登录记录或缓存等同于已加载模型。

playback.py 以单调时钟扣除暂停区间，暂停释放全部键，继续恢复仍处于按住区间的按键，修饰键先于琴键。控制文件带 schema 与递增序号，原子替换；F7 以按下边沿切换。进度直接回报演奏时间，较旧回报不覆盖新的 UI 请求，暂停后不靠系统时间推进游标。游戏失焦和取消检查不放宽。

mini_player.py 只修改本进程小窗：WS_EX_NOACTIVATE、WS_EX_TOOLWINDOW、TOPMOST 和 WM_MOUSEACTIVATE 的 MA_NOACTIVATE，关闭时恢复窗口过程。独立顶层所有权使主窗最小化时保留显示。窗口置顶不代表能够跨越独占全屏或安全桌面；无游戏 DLL 注入或全局鼠标钩子。
