# 2.0 快速迭代记录

2026-11-01：使用者要求转为快速功能迭代，最终发布时再统一测试和打包。本页记录尚未进入上次便携包的源码改动；旧发布附件不在每轮重建。

- 普通 MIDI / 曲谱导入或拖入后也加入曲目架，记录在个人设置的 shelf_files；重复导入去重，重启后恢复。转谱生成文件继续自动显示，不再只收录这一路。普通导入记录引用本地原文件，不额外复制或移动用户文件。
- 曲目架条目改为单行曲名，省略歌手尾部与轻量 Beta 技术后缀；完整标题、来源类型和路径保留在悬停提示中，原文件与数据名称不变。
- 演奏前默认倒计时改为 3 秒，命令行与重置设置同步。倒计时按应用全局记忆，不随切歌恢复旧方案中的 7 秒；用户仍可自行调整并保存。
- 源码运行窗口增加“开发预览”标题。此电脑的 .build/开发工作台.lnk 直接使用现有开发环境运行当前源码，重启即可读取修改；启动 UAC 仍由使用者确认，不自动操作安全提示。
- 修复钢琴黑白分组的 55ms 滚奏可能越过后续白键组，却仍按旧组序计算松键的问题；先按实际起音排序再排程。
- 原曲声部/旋律＋低音模式的短冲突改为最小局部延后，保留原有 25ms Shift 间隔、8ms 重触发间隔和 5ms 最短按下时间。额外延后最多 50ms，超过时报告原曲位置，不无限拖慢整首，也不悄悄删掉冲突音符。界面和适配报告显示调整数量与最大额外延后；这不消除钢琴混合黑白键原有滚奏。
- 修复结束时较早按下的黑键长音仍未结束，却提前释放 Shift 的边界情况。
- 针对性检查：8 项声部/排程检查、4 项暂停控制检查、3 项交接/曲目架检查通过；另补查既有混合和弦、重复键及停止清理路径。未执行整套发布验证或重打包。
- 对本机最新两份 MIDI 仅做离线排程复现，249→249 音、488→488 音，额外延后上限分别为 1.541ms、18.542ms；按键与 Shift 的逻辑释放检查通过。原 MIDI 未修改、未分发，实际游戏听感仍待使用者反馈。

上次系统另存框的实际点选、游戏悬浮窗和多音听感验收仍保留，见 VALIDATION_2.0.md；本轮不把排程成功当作游戏已完整发声。
