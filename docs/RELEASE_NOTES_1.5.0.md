# 异环演奏工作台 v1.5.0

状态更新（2026-10-22）：用户决定继续完善 1.5，暂不定稿。下文记录已有检查点的内容和验证范围；该包与本地标签保留，不代表后续源码已重新打包。后续范围见 NEXT_STEPS.md。

本次增加置顶迷你播放器，将管理员权限申请移到应用打开时。每次从普通权限打开图形应用时，请手动确认 Windows UAC，随后在同一次使用中的游戏演奏会继承权限。

- 圆角迷你窗显示曲名、时间与进度，支持开始、暂停/继续、停止。拖动标题移动，关闭小窗仅隐藏，可从“播放器”菜单重新显示。
- F7 暂停/继续，F8 停止。暂停时释放按键并冻结进度；继续从当前位置往下演奏，未结束的长音可能重新触发。游戏已经响起的延音不能由暂停按钮消除。
- 小窗采用不激活窗口的置顶方式；主窗最小化时仍可显示。返回主窗会停止当前游戏演奏，切换到其他程序也保持自动停止。

**全屏方式：**鼠标操作迷你窗建议使用无边框全屏。普通桌面置顶窗不能保证覆盖独占全屏；保持独占全屏时可用 F7/F8。程序不向游戏注入覆盖层。

**验证范围：**59 项本地自动测试及独立解压后的 EXE 自检通过，覆盖暂停时钟、键位释放及 Shift 恢复、控制序号、窗口样式和最小化行为；实际 UAC 交互和《异环》中的鼠标点击/独占全屏效果尚未实机确认。命令行转换、自检和包校验不请求管理员权限，也不发送游戏按键。

Windows 下载 NTE-Music-Desk-v1.5.0-Windows-x64.zip，完整解压后运行“异环演奏工作台.exe”，保留 _internal 文件夹。个人设置仍在原数据目录；旧版本发布包保留。音频识别继续是实验功能，1.4.0 的模型及素材许可限制继续适用。
