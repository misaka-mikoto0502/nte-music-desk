# 异环演奏工作台 v2.0.1

2026-11-08 · 易用性与界面整理

本版将导入、调整与演奏分成清晰的区域，减少首页按钮和常驻说明，方便第一次使用时找到主要操作。

## 本版改进

- **固定的三个区域**：左侧导入和曲目架，中央“演奏／调整”页面，底部播放控制。演奏页只需选择乐器与演奏方案，速度、移调、片段、声部、报告和导出集中在调整页。
- **四种基础色与统一控件**：白色承载内容、浅灰组织区域、深色显示文字、绿色标识主操作。按钮和原生下拉框采用柔和圆角、统一留白与焦点反馈，下拉选项以悬浮列表展开。
- **按状态显示操作**：播放区根据试听、倒计时、演奏、暂停和音频处理状态显示对应按钮，保留固定尺寸，减少布局跳动。详细提示附在相关控件旁或悬停时显示。
- **按需提供入门帮助**：侧栏可直接选择内置《小星星》，通过“使用引导”查看三步流程。演奏方案改用更直观的名称，同时兼容已有方案和旧名称。

支持 MIDI／MusicXML 导入、本机音频转谱 Beta、多轨调整、片段与进度续播、迷你播放器，以及可选高级音频引擎。

## 升级与回退

将 `NTE-Music-Desk-v2.0.1-Windows-x64.zip` 完整解压到新目录，关闭旧版后运行其中的“异环演奏工作台.exe”，保留 `_internal`。个人设置、曲目架与转换结果仍位于 `%LOCALAPPDATA%\NteMusicDesk`。旧布局偏好会迁移，首次显示演奏页，此后记住本布局的页面选择。

历史版本包独立保留。回退时关闭新版，再运行旧版本目录的程序；重要个人数据可在升级前另行备份。Source ZIP 包含开发、测试、构建和历史文档。

## 验证与边界

检查结果和人工待验收项目见 [2.0.1 验证记录](VALIDATION_2.0.1.md)。音频识别继续为 Beta，复杂混音、弱音和快速重复音可能有错漏。轻量桌面转谱依赖系统 WebView2 Runtime 与 .NET Framework 4.6.2+；高级引擎需另行配置。

本轮使用无游戏输入的回归与发布检查。实际游戏音色、并行发声、钢琴音高、悬浮窗按钮与前台保持仍需人工验收。
