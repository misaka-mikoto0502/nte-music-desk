# 2.0.1 开发阶段记录

以下保留各阶段当时的描述，全部已整合进最终 2.0.1。初始本地检查点为 archive/v2.0.1-initial-20261108，最终更新说明见 ../RELEASE_NOTES_2.0.1.md。

# 更新记录

## 开发中 · 可重复样例验证 · 2026-11-08

- 新增无游戏输入的工作流验证工具，覆盖 4 组曲谱输入、96 组转换、定位变速与重启、试听、旧方案备份、无效输入和时间报告；可选验证真实音频自动交接与参考音符质量。
- 独立包验证支持指定报告位置，保留正式版本证据。验证结果和音频误音边界见 docs/VALIDATION_WORKFLOWS_2026-11-08.md。

## 开发中 · 完整中文图像字标 · 2026-11-08

- 侧栏改用“异环演奏工具台”七字透明图片字标，全部文字采用统一艺术字，两行组合，不再拆成两字主标和普通文字副标。
- 随包保留透明 PNG 原图，按侧栏尺寸等比例显示；资源缺失时显示完整中文名称。参考来源与生成提示词见 docs/BRANDING.md。

## 开发中 · 演奏设置与报告整理 · 2026-11-08

- 演奏设置按速度和移调分组，重置收至标题旁，更多参数按需展开。数值控件改用横向减号、输入和加号，下拉框简化箭头与悬停样式。
- 速度条使用明音头像作拖动滑块，支持精确输入、方向键微调与双击恢复原速，素材来源见第三方说明。
- 移除“试奏 20 秒”和“回到起点”按钮，进度定位集中到播放区。
- 推荐移调搜索补全 −36 至 +36 的全部 73 个半音，纳入实际排程延后；同分优先保持当前移调。推荐窗口显示最多延后量，保留应用前的设置过期检查。
- 适配报告将“原曲／秒”改为“原曲位置（分:秒）”，例如 180 秒显示为 03:00.000；单独显示原曲总长、本次演奏时长和速度，JSON 保留精确秒数。

## 开发中 · 入口与演奏页简化 · 2026-11-08

- 点击导入和拖入文件共用侧栏“导入音乐”按钮，Ctrl+O 与文件菜单也使用同一入口。
- 侧栏以原创中文“异环”线条艺术字替换 NTE，配合“演奏工作台”副标，沿用四种基础色。
- 移除界面上的演奏片段输入，通过进度条选择开始位置；“原谱对照”移至演奏页，从当前进度试听。
- 载入旧片段方案时先保留 `.excerpt.backup.json`，再使用完整时间轴；其他方案参数和已记忆的位置继续保留，命令行片段转换继续支持。

## 2.0.1 · 易用性与界面 · 2026-11-08

- 主窗采用固定曲目栏、演奏／调整页面与底部播放区。演奏页只放乐器与方案，参数和检查工具按用途集中。
- 曲目栏提供内置《小星星》，三步引导从侧栏和帮助菜单打开。主窗采用纯色背景，常驻说明移至相关控件的悬停提示。
- 共享原生界面使用白、浅灰、深色与绿色四种基础色，主操作填充绿色，次级操作使用浅底。试听、停止和暂停按钮根据任务状态切换。
- 按钮采用浅底与统一圆角，并增加悬停、焦点和按下反馈。原生下拉框更换圆角输入面、箭头与弹出列表样式。播放区预留固定操作尺寸，状态提示固定两行，减少状态切换时的布局跳动。
- 演奏方案使用直观名称并兼容旧名称和已有方案，保留独立声部、试听与演奏功能。应用、源码包与 Windows 文件属性统一为 2.0.1。
