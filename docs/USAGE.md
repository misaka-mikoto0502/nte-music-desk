# 异环演奏工作台 · 使用说明

Windows 64 位便携版：完整解压后双击“异环演奏工作台.exe”。无需安装 Python，保留同目录的 `_internal` 文件夹。程序默认使用普通权限，开始游戏演奏时才通过 Windows UAC 请求运行演奏进程，需手动确认。

## 开始演奏

1. 选择内置《小星星》，或者点击“导入曲谱”选择 MIDI、MusicXML 或 MXL。
2. 顶部选择“吉他 · 钢琴模式”或“钢琴 · Shift 黑键”。在游戏里也进入对应的 36 键乐器界面。
3. 蓝色“电脑试听”播放前 20 秒合成音色，只用于确认曲谱，不操作游戏。
4. 琥珀色“游戏试奏”演奏前 20 秒。手动确认 UAC，保持游戏前台并松开键鼠；默认倒计时 7 秒。
5. 试奏满意后点击青绿色“完整演奏”。

F8 停止；Esc 也会停止，但可能同时退出游戏演奏界面。切出游戏或游戏关闭会自动停止，并释放程序按住的琴键与 Shift。工具的红色“停止”按钮也可取消演奏和试听。

工具核对游戏窗口标题与 HTGame.exe，不能自动识别当前是否进入了正确乐器界面。

## 搜索曲目

点击“在线搜曲”，输入曲名并搜索；选择版本后点击“下载并导入”。工具下载、校验 MIDI、选择推荐音轨并返回演奏页，不会自动演奏。已下载页可以再次载入，无需重复下载。

目录快照共 122,120 条：BitMidi 113,229、动漫公开目录 6,769、Mutopia 古典 2,122。Mutopia 有 796 个条目标有钢琴，可在来源下拉中单独选择“Mutopia 古典”。支持“致爱丽丝”“贝多芬 月光”“肖邦夜曲”“巴赫前奏曲”等中文组合；钢琴编配会优先排序。无结果可试英文或日文。最多显示前 100 条，增加关键词可缩小范围。

Mutopia 部分作品用 ZIP 提供多个乐章。下载时保存该选定作品的全部 MIDI 乐章，按文件名自然顺序载入第一首；其余在“已下载”页切换。曲目详情和来源记录保留作曲家、乐器与许可。“更新目录”手动联网刷新，失败时保留旧目录。仅选中下载时才获取 MIDI，不批量下载整站。超时或 502 错误可稍后重试，来源拒绝访问时也可打开来源网页。工具不处理登录、付费或验证码。

三叶与黄昏为搜索快捷入口。已有的两首本地曲谱仍可通过“导入曲谱”打开。软件包只附自制《小星星》示例，不附第三方曲谱原件。

## 导入格式与转换

| 文件 | 本版支持 | 方式 |
|---|---|---|
| .mid / .midi | 是 | 标准 MIDI 0/1 |
| .kar | 是 | 读取其中的 MIDI 音符，不显示歌词 |
| .rmi | 是 | 读取 RIFF MIDI 容器中的音符 |
| .musicxml / .xml | 是 | score-partwise MusicXML |
| .mxl | 是 | 压缩 MusicXML，按容器声明读取主曲谱 |
| .mscz / .mscx、Sibelius、Finale 工程 | 需先导出 | 用原制谱软件导出 MusicXML/MXL 或 MIDI |
| MP3 / WAV 等录音 | 不能直接导入 | 先用音频转谱工具识别，再导出 MIDI |
| PDF / 乐谱图片 | 不能直接导入 | 先用乐谱识别 OMR 软件校对并导出 MusicXML |

MusicXML 导入保留显式音高、时值、休止、声部、和弦、连音和速度变化，支持普通反复及编号房子。无时值装饰音和颤音记号不展开；D.C./D.S./Coda/Fine 跳转会显示警告。小节内反复、嵌套反复、不一致的声部反复、微分音及 score-timewise 暂不支持，请先在制谱软件中展开或改用 MIDI。只含第一页的片段若缺少反复终点，也会提示检查曲谱。文件最大 16 MB，MusicXML 展开主文件最大 8 MB。

导入后可直接试听和演奏，也可点击底部“另存 MIDI”或菜单“文件 → 另存原曲为 MIDI”，把原曲全部声部转成标准 MIDI。此导出不应用当前游戏演奏的选轨、变速、移调或简化；保留音符的秒级时刻，使用统一 120 BPM 网格保存，不保留原始速度标记、排版、歌词或踏板。JSON“导出曲谱”则保存当前游戏演奏设置下的结果。

MP3 转 MIDI 属于音符识别而非无损格式转换，独奏通常更合适，混音、演唱和复杂伴奏可能产生错音。可了解 [Spotify Basic Pitch](https://basicpitch.spotify.com/)，本工具不会自动上传音频，也不内置音频或图片识别模型。对于古典钢琴，优先选现成 MIDI 或 MusicXML。

## 乐器与和弦

同一份 MIDI 切换乐器时，工具会自动重新转换键位与音域，无需额外音频或转换软件。

- 吉他钢琴模式：E3–D#6，三排独立半音键；旋律版与最多 6 音和弦版。
- 钢琴：白键低音 Z X C V B N M、中音 A S D F G H J、高音 Q W E R T Y U；黑键为对应白键加左 Shift，暂按 C3–B5 编排。界面没有绝对音高，必要时用移调 ±12 校准八度。Ctrl 降半音在游戏中可用，但程序统一使用 Shift 表达黑键。
- 旋律版在相隔不超过 25 毫秒的一组音中只保留最高音；它是简化规则，不保证自动找到所有曲目的主旋律。
- 和弦版最多保留同组 6 音。MIDI 必须含有和弦或伴奏，单旋律不会自动增加伴奏。左右手分轨时按 Ctrl 多选音轨。
- 钢琴全白键或全黑键和弦成组按下；混合黑白键先白后黑，约错开 55 毫秒。这是滚奏近似，音色、延音和多音上限取决于游戏。过密的曲谱会提示降低速度或减少音轨。

## 常用设置

速度 1.0 是原速，0.8 更慢，1.2 更快；支持 0.25–2。移调单位为半音，±12 为一个八度。修改参数会自动更新曲谱。高级设置可以调整原 MIDI 起始秒数、倒计时、每音按键上限和超出音域的处理方式。

“八度折回”保留音名但会改变旋律的上下走势，也可选择丢弃越界音或报错。程序保留音符起点与速度变化，不将力度、延音踏板、弯音、录音或原乐器音色转换成操作。默认每音最多按住 300 毫秒，游戏长音触发后自然延音。

展开“键位预览”可看前 8 音，“曲谱明细”列出完整键位。“导出曲谱”保存当前转换后的 JSON；演奏无需事先手动导出。

## 数据与快捷键

默认数据目录：%LOCALAPPDATA%\NteMusicDesk。菜单“文件 → 打开数据目录”可直接查看。

- midi_ui_settings.json：上次曲目、最近导入、乐器、速度和移调。
- downloaded_midis：下载 MIDI 及 .source.json 来源记录。
- catalog_cache：手动更新后的目录缓存。
- runs：各次演奏曲谱、进度和结果；completed 只表示发送完成。
- logs：异常日志（发生启动或操作错误时生成）。

升级时用新版软件目录替换旧版，个人数据不会随软件覆盖。备份上述数据目录即可保留已下载曲目与设置。导入的外部文件仍引用原文件，请自行保留。

Ctrl+F 在线搜曲，Ctrl+O 导入，Ctrl+Enter 完整演奏，F8 停止。前三个在工具窗口内使用，演奏时 F8 在游戏中也有效。
