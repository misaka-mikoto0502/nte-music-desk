# 异环演奏工作台 v2.0.2

2026-11-09 · 完整离线转谱与后台演奏

这次更新把本地音频转谱做成完整便携功能：下载、解压即可使用，转谱期间也能继续选曲和演奏；迷你播放器可以直接拖动明音进度条、点击曲名换曲。

## 本版改进

- **完整离线转谱**：钢琴曲使用 Transkun 2 ONNX，歌曲／含人声使用 GAME small＋MuScriptor small，分别保留演唱旋律与其他声部。模型、CPU 运行库和解码器全部随 Windows 包提供，无需 Python、CUDA、账号、WebView2 或首次联网下载。
- **更快的 CPU 处理**：修复 F16C 硬件转换并减少歌声推理缓存与空闲线程占用。定版前同实现处理 288.301 秒歌曲实测 **149.813 秒，约 2 分 30 秒**，全部原始事件与 MIDI 和认可基准逐字节一致；不同硬件、曲长和负载下耗时会变化。
- **后台转谱，继续演奏**：点击“后台运行”收起转谱窗口，继续使用主窗或小窗。后台完成只加入曲目列表，保留当前曲目和播放；停止演奏与取消转谱互不影响。
- **更顺手的迷你播放器**：主窗开始演奏后自动聚焦游戏并显示小窗，鼠标操作保留游戏焦点。明音头像随进度移动，支持点击和拖动定位；点击曲名展开可滚动列表换曲。演奏中先释放旧曲按键再开始下一首，暂停／空闲时只载入。
- **曲目列表管理**：右键重命名显示名称，曲目栏、当前大标题和小窗同步；从列表移除保留原文件、演奏方案及续播位置，重新导入可恢复。
- **状态与边界修复**：换音频／识别类型／选段后清空旧结果展示；后台期间换曲再返回也保留用户选择。文件失效、取消、失败、安全中断及连续换曲均有相应处理，避免旧结果覆盖或意外续播。

## 下载与升级

普通用户下载 **`NTE-Music-Desk-v2.0.2-Windows-x64.zip`**，约 355 MB，完整解压后约 461 MB。关闭旧版，再双击“异环演奏工作台.exe”，保留 `_internal` 文件夹。Source ZIP 供开发构建，不包含模型与运行环境。

个人设置、曲目架、演奏方案和转谱结果仍在 `%LOCALAPPDATA%\NteMusicDesk`，升级保留。F7 暂停／继续，F8 停止；切出游戏也会停止。

**管理员权限用于兼容向高权限游戏窗口发送模拟按键。** 当前在打开主界面前请求一次 UAC，需手动确认，取消则不启动；权限由整个应用及其演奏、音频子进程继承。读谱、转谱和试听本身不需要提权。演奏通过 Windows 模拟键盘，不使用游戏进程注入或修改游戏文件。

## 验证与边界

176 项 Python 检查、96 组转换及 JavaScript 检查通过；真实模型、后台并行、迷你播放器换曲、失败重试和独立 Windows 包分别验证。完整记录见 [本版验证](VALIDATION_2.0.2.md)，质量指标与性能条件见 [离线转谱记录](VALIDATION_OFFLINE_AUDIO.md)。

音频识别继续标为 **Beta**，密集混音、人声滑音、混响和快速重复音仍可能有错漏；合成试听不等于游戏原音色。自动检查未向真实游戏发送按键，游戏内音高、发声与独占全屏覆盖仍需实机确认；鼠标操作推荐无边框全屏。
