# 2.1.0 发布验证

2026-11-13 在 Windows x64 上完成本地验证。开发者可按 [构建与发布](RELEASING.md) 复现测试和独立解压自检。

| 检查 | 结果 |
| --- | --- |
| Python 回归 | 144 项通过，覆盖只读下拉框、适配报告、原谱保留、F6 小窗开关和后台转谱。已移除的旧转谱工具不再计入测试。 |
| 常规曲谱 | MIDI、MusicXML、压缩 MusicXML 和多轨样例共 96 组转换通过。 |
| 密集曲谱 | 本轮钢琴适配验证使用 4 份本地转谱 MIDI，共 392 组排程通过，原文件校验值一致。《Summer》丰富声部从转换后的 1249 音排到 1230 音，合并 19 音，剪枝 0 音。 |
| 迷你播放器 | 换曲、暂停后载入、停止取消换曲、自然播完复位，均通过子进程调度验证。 |
| Windows 便携包 | 独立解压后，自检、曲谱片段转换及源码与产物一致性检查通过。已核对包内模型清单。 |
| 实际离线转谱 | 6.6 秒钢琴短句和约 33 秒钢琴与人声混音均在正式 EXE 中生成 MIDI 与试听文件。 |

密集曲谱的样例、局部时间约束及删音统计见 [钢琴通用适配](PIANO_ADAPTATION.md)。正式 Windows ZIP 约 352 MB，主要体积来自当前离线模型。精确大小、校验值及机器可读记录随本地发布产物保存。

软件检查不向游戏发送按键。游戏内多音表现、听感和当前版本的权限提示需由使用者在桌面实机确认。
