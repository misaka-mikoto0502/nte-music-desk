# 2.1.0 发布验证

2026-11-13 在 Windows x64 上完成本地验证。开发者可按 [构建与发布](RELEASING.md) 复现测试和独立解压自检。

| 检查 | 结果 |
| --- | --- |
| Python 回归 | 187 项通过，含只读下拉框、适配报告和原谱保留。 |
| 常规曲谱 | MIDI、MusicXML、压缩 MusicXML 和多轨样例共 96 组转换通过。 |
| 密集曲谱 | 4 份本地转谱 MIDI 共 392 组排程通过，原文件校验值一致。《Summer》丰富声部从转换后的 1249 音排到 1230 音，合并 19 音，剪枝 0 音。 |
| 兼容转谱与迷你播放器 | JavaScript 进度、保存、重试测试及迷你播放器子进程换曲检查通过。 |
| Windows 便携包 | 独立解压后，自检、曲谱片段转换及资源一致性检查通过。 |
| 实际离线转谱 | 6.6 秒钢琴短句和约 33 秒钢琴与人声混音均在 2.1.0 EXE 中生成 MIDI 与试听文件。 |

密集曲谱的样例、局部时间约束及删音统计见 [钢琴通用适配](PIANO_ADAPTATION.md)。正式 Windows ZIP 为 353,066,432 字节，较 2.0.2 少 2,370,993 字节。校验值及机器可读记录随本地发布产物保存。

软件检查不向游戏发送按键。游戏内多音表现、听感和当前版本的权限提示需由使用者在桌面实机确认。
