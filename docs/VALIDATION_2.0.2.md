# 2.0.2 发布验证

定版日期：2026-11-09。由使用者确认将已验证的离线开发版本定为 2.0.2；代码继续维护在 `release/2.0.0`，使用 `v2.0.2` 标签，既有发布包及标签保留。

## 功能与使用场景

| 范围 | 验证内容 |
| --- | --- |
| 自动回归 | 176 项 Python 检查；版本元数据、随包帮助、GUI 状态、曲目管理、进度定位、暂停、停止、安全中断及构建目录保护。 |
| 曲谱工作流 | 96 组 MIDI／MusicXML／MXL／多轨转换，两种游戏乐器、四种演奏方案、三档速度；旧方案迁移、原曲位置保持、移调推荐与时间显示。 |
| 原生转谱 | 缺失／损坏音频、越界选段能报错并重试；切换文件清空旧结果，重复同一文件保留有效结果，迟到回调不覆盖新任务。 |
| 后台转谱 | 取消真实转谱不停止播放，继续生成试听、暂停／定位／继续可用，完成不切换当前曲目；先换曲再回到原曲也保持用户选择。 |
| 小窗换曲 | 播放子进程无重叠，旧按键释放后开始新曲；暂停只载入，停止取消待切换曲目，自然播完复位。失焦、修饰键、F8／Esc、进程错误和未知中断后不自动开始新曲。 |
| 文件与布局边界 | 目标在换曲等待期间被删除／损坏、空曲目架、隐藏条目、长标题、滚动列表、屏幕底部向上展开、明音进度条两端定位。 |
| 旧轻量工具 | JavaScript ETA、整理与保存、延迟进度、WASM／CPU 回退、取消及下载保存。 |

前述真实 UI／调度检查只使用记录按键的后端，没有发送系统键盘输入。真实转谱包含模型推理，与仅模拟任务回调的检查分别保留。

## 识别质量与性能

定版前相同功能实现的 288.301 秒完整歌曲：Windows 便携包总耗时 149.813 秒，最终 1,933 音；歌声、伴奏、合并事件与 MIDI 均与认可基准逐字节一致，在 Ryzen 7 7745HX CPU 上通过 180 秒门槛。此结果不是所有硬件和曲目的完成时限，也不是人工标注准确率。

真实后台 15 秒受控人声／钢琴混音输出 72 音，与相同选段基准一致；三和弦参考／预测各 16 音，MIDI 与原基准一致。完整质量口径、已知误音、结束时间评分和上游端口一致性见 [详细记录](VALIDATION_OFFLINE_AUDIO.md)，不重复宣称任意曲目的准确率。

2.0.2 正式包独立执行钢琴与歌曲样例：三和弦 16 音，15 秒受控混音 72 音，原始事件与 MIDI 均与基准逐字节一致。另将 37 个应用代码模块与上一轮已验证便携包比较，确认仅版本常量由 2.0.1 改为 2.0.2；离线资源清单完全相同，正式包不含开发预览标记。完整歌曲性能沿用上述相同实现的实际记录，没有将短片段速度外推为整首结果。

## 便携包与源码完整性

正式包检查包括 ZIP SHA-256／CRC、中文空格目录解压、仅 System32 PATH、独立冻结自检、片段转换、完整离线资源及许可证、安装资源只读。模型测试关闭在线访问，不使用外部 Python／FFmpeg。

`tools/verify_current.py` 逐文件核对 Source ZIP 与工作区、Windows ZIP 与展开应用、资源与源码，以及 EXE 内嵌的 37 个应用代码模块。机器报告、最终体积和校验值位于本地 `releases/v2.0.2/verification.json`、`SHA256SUMS.txt` 与 `.build/validation/release-2.0.2/`；这些产物不提交 Git。
