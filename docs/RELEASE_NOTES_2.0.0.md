# 异环演奏工作台 v2.0.0

把本地曲谱或音频带进工作台，试听适配结果，再由工具自动操控《异环》中的钢琴或吉他钢琴模式。

## 这次更新

- **音频直接转谱**：默认使用独立桌面窗口，本机 CPU 运行小型 Basic Pitch 模型，无需 Python、GPU 或账号。支持选段、进度与预计剩余时间，加速不可用时自动回退兼容模式。
- **拖入即可处理**：主窗口支持拖入 MIDI、MusicXML 和音频；音频窗口支持点击选择或拖入。曲目架更简洁，转谱页左右分栏。
- **结果自动留存与交接**：生成的 MIDI 自动加入曲目架并载入工作台，重启后仍可选择，无需先下载再导入。完成后继续自动下载到系统下载目录；手动点击“下载 MIDI”会弹出另存为，可选择目录和名称，候选谱和对齐前结果也支持另存。正在演奏时先加入曲目架，结束后载入。
- **演奏控制更方便**：启动时确认一次 UAC，演奏继承权限；置顶迷你播放器支持演奏、暂停/继续和停止，F7/F8 可在游戏中控制。
- **保留高级音频处理**：可选 UMX-HQ 人声/伴奏分离、MuScriptor 多轨转谱和 GAME 旋律 Beta，支持双路输出和同位置试听。这部分需独立配置依赖及模型许可，未打入轻量包。
- **统一与修复**：各入口共用转换、保存和取消流程；避免音频任务与演奏并发抢占，拒绝超时任务的迟到结果，统一版本、帮助和发布检查。

## 使用与升级

下载 `NTE-Music-Desk-v2.0.0-Windows-x64.zip`，解压到新目录，保留 `_internal`。关闭旧版，再运行新目录中的“异环演奏工作台.exe”。无需删除 `%LOCALAPPDATA%\NteMusicDesk`，原有曲谱和演奏方案继续保留；重要个人文件可自行备份。

轻量桌面窗口复用系统 WebView2 Runtime 与 .NET Framework 4.6.2+，不分发浏览器内核。系统缺少组件时会提示，可手动选择“文件 → 轻量转谱（浏览器兼容）”。源码包是供开发者构建使用的，不是用户运行包。

## 已知边界

音频识别继续为 **Beta**，清晰单乐器效果优先；复杂混音、人声与弱音可能有错漏。弱音预设可能增加误判，起音对齐默认关闭。不承诺所有歌曲达到 90–95%，也不还原原曲音色、踏板和弯音。

钢琴的混合黑白键使用全局 Shift，约 55ms 分组触发；吉他钢琴模式没有这项分组限制。置顶窗推荐配合无边框全屏，独占全屏可使用 F7/F8。实际多音数、钢琴绝对音高及新包悬浮窗按钮仍需人工确认，具体证据与待验收项见 [发布验证](VALIDATION_2.0.md)。

工具不提供搜曲或音乐下载，请合法合理使用本地输入和转换结果。音频不上传外部服务；可选引擎首次安装/获取模型可能联网，代码、模型和音乐素材各自许可分别适用。软件与游戏官方无关联。
