完整离线包分发未修改的 Transkun 2 ONNX、MuScriptor small GGUF 与 GAME small ONNX，以及 NumPy/ONNX Runtime、精简 LGPL 解码器与本机 CPU 程序。MuScriptor 与 GAME 权重分别受 CC BY-NC 4.0（附上游使用条件）和 CC BY-NC-SA 4.0 约束。完整许可、署名和模型卡随包保留；详见 OFFLINE_AUDIO.md。

核对日期：2026-10-22。本文记录产品边界与已核对的上游声明，不是对任意歌曲、模型训练数据或发布行为的法律合规保证。

## 本地文件方案的作用

工作台定位为处理用户自有或已获必要授权素材的本地工具。v1.4.0移除搜曲、音乐下载、预置歌曲搜索与目录快照；不提供商业歌曲、伴奏或识别结果的下载。已有本地文件仍能手动导入。完整便携包的转谱在本机运行。

这样减少了项目主动获取、提供音乐内容的风险，但不能得出“只要用户提供文件，开发者就绝对无责任”。是否构成侵权仍取决于实际功能、用途、是否明知或帮助侵权等具体事实。声明、勾选框与本地文件位置均不创造授权。

## 需要分别判断的权利

- 输入：音乐作品、具体编曲、录音及表演可能涉及不同权利。付费购买、订阅下载或公开试听不自动授权转谱、改编或再次传播。
- 转换：分离人声、转成 MIDI、换乐器或由游戏重新发声，不会自动消除原音乐的权利。是否属于法定例外，需结合实际情况判断。
- 发布：仅在本机试用，与向粉丝发 MIDI、提供伴奏、上传游戏演奏视频，是不同使用行为；发布前分别核对权限，平台允许上传也不当然证明取得全部授权。
- 古典素材：原作保护期届满，不等于现代编曲及某个录音均可自由使用。优先使用自行录制、自己合成或权利链与许可明确的样本。

[《著作权法》](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)第十条规定复制、表演、改编和信息网络传播等权利；第二十四条的个人学习等例外有署名、不影响正常使用、不不合理损害权益等条件。免费、非商业或“仅供学习”不能一概替代法律适用判断。公开提供服务、收费或商业合作前，应就具体方案作专业审查。

## 当前程序落实

工作台只转谱用户选择的本地音频，模型在本机执行。完整模型卡与许可位于便携包的离线转谱资源目录。

此前《漫长的告白》的公开试听及曲谱研究，没有建立可向粉丝或 GitHub 分发的完整授权依据，因此不将其作为发布样本，也不继续用于模型验收。后续采用自制或许可明确的样本。旧的本地研究文件保留在仓库外，不替用户删除；不将这些文件视为已获传播授权。
