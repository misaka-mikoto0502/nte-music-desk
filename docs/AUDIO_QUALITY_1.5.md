## 本轮处理

- 保持默认阈值 onset=.7、frame=.4、最短 11 帧，保留现有均衡行为。
- 可选多保留弱音：onset=.55、frame=.3、最短 7 帧，关闭额外 melodia 恢复；可能恢复较弱或较短候选，同时可能增加错误。诊断 MIDI 另用更宽松阈值及 melodia 策略。
- 可选 24 毫秒起音对齐，默认关闭；不改整体速度，不按节拍网格量化，不跨窗口连续吸附，不删音；重复同音或延音冲突组保持原样。
- 保存对齐前的 `model_selected.mid`，诊断 MIDI 与原录音不覆盖；来源记录写入处理参数和实际移动音数。
- 两首现有结果在该选项下分别有 45 / 50 音可移动，最大提前约 23.958 毫秒。只是算法统计，新结果的游戏听感尚待使用者验收。

## 为什么不直接补回所有候选

同一 CC0 钢琴采样库合成的六份短句，以准确音高与起音 ±100 毫秒一对一匹配；用于参数选择，不是独立真实歌曲泛化验收。

| 短句 | 均衡 F1 | 宽松 F1 | 均衡漏音 / 额外音 | 宽松漏音 / 额外音 |
| --- | ---: | ---: | --- | --- |
| scale | .865 | .780 | 0 / 5 | 0 / 9 |
| arpeggio | .889 | .727 | 0 / 4 | 0 / 12 |
| repeated | .696 | .667 | 0 / 14 | 0 / 16 |
| triads | .968 | .833 | 1 / 0 | 1 / 5 |
| legato | .762 | .640 | 0 / 5 | 0 / 9 |
| dynamics | .815 | .687 | 1 / 4 | 1 / 9 |

宽松预设没有普遍提高质量，故作为可选实验保留，不能标为增强准确率。若均衡版已接近预期，先只比较轻微起音对齐；有意的分解和弦保持关闭。输出单轨、多乐器重叠和人声混音仍是小模型的边界，重型引擎不作为默认交付。

新增回归覆盖参数边界、对齐时间界限、非连续吸附、重复同音保留、松音时间/原始输入不变，以及 HTTP 保存对齐前/后 MIDI 与处理记录。未把短句分数当作任意 MP3 的 90–95% 正确率。
