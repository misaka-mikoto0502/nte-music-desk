# 2.0.2 展示视频录制提纲

建议成片 2 分 40 秒左右，面向首次接触的用户，突出“解压可用、转谱能后台跑、在游戏中直接控制”。版本对比可从 1.0.0 的曲谱演奏，过渡到 2.0.2 的完整离线工作流；只有旧版素材可证明的画面才用于前后对比。

| 成片时间 | 录制内容 | 字幕要点 |
| --- | --- | --- |
| 00:00–00:12 | 游戏中的一小段演奏，再切到工具台 2.0.2 主窗。 | 从曲谱演奏，到完整离线音乐工作台。 |
| 00:12–00:38 | 拖入自有钢琴音频，选择“钢琴曲”并开始。另录完成画面，剪辑时用转场衔接。 | 自带模型和运行环境，解压即可转谱，音频不上传。 |
| 00:38–01:00 | 打开对照试听，在原音频与识别曲谱间切换；展示和弦与低音声部。 | 钢琴专用识别，先对照，再适配。 |
| 01:00–01:25 | 新建一次转谱任务，点击“后台运行”，选择已有曲目并开始演奏。 | 转谱期间继续用，完成只加入列表。 |
| 01:25–02:00 | 自动切到游戏并弹出小窗；演示 F7 暂停／继续、拖动明音进度、点击曲名换曲。 | 小窗直接定位和换曲，保持游戏焦点。 |
| 02:00–02:20 | 停止后回主窗，右键重命名，再从列表移除一首测试曲。 | 名称同步更新，移除保留原文件。 |
| 02:20–02:40 | 一段完成的演奏收尾，显示版本与下载位置。 | 2.0.2：完整离线、后台处理、顺手演奏。 |

录制前手动完成 UAC 并进入游戏对应的 36 键乐器界面，使用无边框全屏。需要说明权限时用一句字幕：“管理员权限用于兼容向高权限游戏窗口发送模拟按键。”

建议原始素材分段保存：主窗／转谱、对照试听、后台任务、游戏小窗、曲目管理、收尾演奏。转谱的开始与完成都录下，实际等待不必全部放进成片；不要用转场暗示任意音频都能瞬间识别。结尾可标注“音频识别 Beta，复杂混音需试听校对”。
