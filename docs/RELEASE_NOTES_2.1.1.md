# 异环演奏工作台 v2.1.1

> **启动前请知悉 · 每次从普通权限打开工作台时，Windows 会请求一次管理员权限。**
>
> 这是为了向以管理员权限运行的《异环》发送演奏按键。授权适用于本次运行的工作台及其启动的子进程。演奏、换曲和续播时无需再次确认。取消授权则退出工作台。

本版为 2026-11-23 更新的 2.1.1 本地阶段归档，完成分段精修与内嵌转谱页；社区暂以“计划实现”占位。本轮未上传 GitHub，2026-11-19 的旧归档保留。

- “分段”先选择整曲乐器，再选区、分割和调整；“游戏试奏 A · 当前”和“游戏试奏 B · 候选”在游戏内比较同一选段，沿用窗口确认、倒计时、暂停与停止保护；候选仅在应用后保存，比较不改变整曲续播位置。
- “转谱”与演奏、调整并列，切页继续任务，后台完成只加入曲目列表。
- “社区”仅保留计划提示，暂不展示发布、下载、连接和本机 Demo 操作，也不启动社区轮询。已有 `.nteproject` 工程可继续通过统一导入入口打开。
- 拖动选区端点、移动或新建选区时，定位游标保持独立；“放大选段／查看全曲”以绿色与勾选标记显示当前视图。应用后的音符标为橙色，支持撤销重做及自动保存。
- 收起的下拉框不再用滚轮切换选项，鼠标经过时继续滚动页面；点击曲目保留列表原有顺序。
- 明音头像由 26 放大至 32 逻辑像素，集中头部取景并从原图直接按显示比例取样。夜景背景固定取景，修复分页空白、滚动黑框，以及切换乐器后操作已删除背景层的连续报错。
- 概览音符采用可复用图层，拖选只更新选区和游标；跳过视口外重绘，背景裁切到可见区域，减少重复转换与按钮尺寸测量。性能结果和边界见 [流畅性记录](RESPONSIVENESS.md)。

本版更新游戏窗口识别。国服和国际服共用同一个 Windows x64 便携包，打开游戏后由工作台自动识别窗口。

- 通过 `HTGame.exe` 的游戏进程和窗口类识别主窗口，兼容不同语言、空标题及原有简体标题。[关联反馈](https://github.com/misaka-mikoto0502/nte-music-desk/issues/5)
- 找不到游戏或检测到多个候选窗口时，会提示启动游戏或只保留一个客户端。找到唯一目标后，点击演奏先确认游戏处于前台，再开始倒计时。演奏中切出游戏会停止。

完整解压 `releases/v2.1.1/final-20261123/` 中的 `NTE-Music-Desk-v2.1.1-Windows-x64.zip` 到新目录，保留 `_internal` 后打开「异环演奏工作台.exe」。此前 final 与 workspace-demo 包作为历史快照保留。

多语言窗口识别已覆盖软件回归和 Windows 模拟窗口场景。国际服实机可用内置《小星星》确认切换到游戏、实际发声以及 F8 停止。
