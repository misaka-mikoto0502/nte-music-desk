# 音频引擎的体积与部署约束

2026-10-22，1.5 开发阶段。本文区分已实现的约束与尚待实现的交付方式。

新增轻量路径已实现：Basic Pitch / TensorFlow.js CPU 在已有浏览器中离线运行，模型、脚本、页面和许可共约 2.33 MB，无需安装运行环境。质量为 Beta，不能宣称任意音乐达到 90–95%。以下 small/medium 和私有 Python 组件计划专指高级音频路径；暂不推进重型免配置套件作为默认交付。详见 LIGHT_AUDIO.md。

## 已落实

- 产品只允许 MuScriptor small（约 0.1B）和 medium（约 0.3B）。参数量来自官方模型卡，是近似值；不是运行内存预算。large 约 1.3B，已从界面、任务验证和模型访问入口移除；旧偏好中的 large 回退为 medium。
- medium 当前官方权重文件约 1.23 GB，加载时还需 Python、PyTorch、解码器、激活与缓存。小于 1B 不代表适合所有 CPU 或低内存电脑。
- CPU 和自动安装明确使用 PyTorch 官方 CPU wheel 源；只有显式选择 NVIDIA GPU 才安装 cu128 组件。自动安装得到 CPU 环境，后续希望使用 GPU 时需显式安装相应组件。
- 安装时固定 +cpu / +cu128 wheel 标签，已有另一种配置时也能切换；音频子进程默认将 OpenMP/MKL 限为 4 线程，已有用户线程设置优先。
- large 的本轮开发缓存已清理，未加载推理；不继续下载或测试大于 1B 的方案。主程序没有捆绑任何模型。

## 目标交付方式（尚未实现）

1. 主程序继续包含曲谱导入、编辑和游戏演奏所需环境。导入 MIDI 不要求 GPU、Python 或音频组件。
2. 提供独立的 Windows x64 CPU 音频组件，包含私有运行环境、依赖、解码器和许可证。由主程序调用独立进程，用户无需安装 Python、修改 PATH 或输入 pip 命令。Python 可以作为私有文件包含在组件内，不必成为系统环境。
3. 首次使用音频功能时显示下载体积和目标目录，支持取消、校验、失败重试与原子安装。另提供离线运行环境包。模型单独管理；运行环境与模型不是同一份下载。
4. GPU 加速为可选组件；不能要求所有人安装 CUDA Toolkit。仍需兼容的显卡驱动；检测失败应明确提示选择 CPU，不偷偷重新下载其他模型或运行环境。
5. 门控权重沿用用户本人的授权，不能把开发者账号、令牌或缓存直接打包给所有人。离线包默认只包含运行环境；模型是否可随包分发必须另外核对许可、附加条款与再分发条件。用户可导入自行获准下载的权重。

当前开发版仍需先选择完整 Python 创建独立环境；上述无需 Python 的组件安装器及离线包尚未交付，不能宣传为已支持。

## 选型与验收

优先比较许可清楚的 CPU 轻量模型，MuScriptor small/medium 保留为进阶选择。以相同的已知曲谱音频记录漏音、额外音、起音和持续时间误差，以及冷启动耗时、纯推理耗时、进程峰值内存、磁盘占用。已知钢琴基准仅为 8.5 秒，不能外推为整曲质量或所有机器的速度保证。

默认方案必须在无 Python、无 CUDA、禁用 GPU 的干净 Windows 环境完成安装和转谱；离线环境单独验收。候选模型质量未达标或代码/权重授权不清楚时，不因体积小就设为正式默认。

参考：[MuScriptor medium 模型卡及型号表](https://huggingface.co/MuScriptor/muscriptor-medium)、[PyTorch 官方 CPU / CUDA 安装方式](https://pytorch.org/get-started/previous-versions/#v280)、[Spotify Basic Pitch](https://github.com/spotify/basic-pitch)。
