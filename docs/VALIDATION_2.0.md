# 2.0.0 发布整合验证 · 2026-11-01–02

本轮按使用者要求完成 2.0.0 的软件整合、独立检查和本地打包，游戏实际测试跳过。当前分支 release/2.0.0，不自动推送 GitHub、建立标签或发布 Release。此前快速迭代的源码改动现已进入本次 Windows 包，变更明细见 [迭代记录](ITERATION_2.0.md)。本页取代先前 94 / 96 项测试及旧附件数据。

## 整合范围

- 普通 MIDI / MusicXML 导入及拖入也加入曲目架，重启恢复；曲目架采用单行曲名，默认倒计时 3 秒且全局记忆。
- 主窗、小窗支持点击和拖动定位，记住原曲播放位置，暂停/停止/退出后可续播。变速不改变记忆的原曲时刻；原谱与按键时序试听跟随当前位置。
- 钢琴短冲突做有上限的局部延后，修复黑白组排序与末尾 Shift 释放；可选原曲 24ms 起音对齐，默认关闭，原 MIDI 不改写。
- 本机轻量音频转谱、ETA、CPU 加速与回退、拖入、自动下载、手动另存、自动交给工作台使用同一套流程。
- 同一次模型推理保留两档识别结果，免重算切换并载入。新识别 MIDI 统一力度 96，未估计原曲真实强弱；已有 MIDI 不修改。
