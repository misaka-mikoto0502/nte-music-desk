# 异环演奏工作台 v2.1.0

2.1.0 解决了密集钢琴谱在部分演奏方案下无法开始的问题。导入转谱结果后，可以先用“保留丰富声部”试听，工作台会对有冲突的按键做局部调整。

- **密集钢琴谱自动适配。** 四种钢琴演奏方案都可使用。先合并八度折回后重叠的同键音，再重新分组和局部延后，仍有冲突时按声部、音区、力度和时值减少局部音符。原始 MIDI 和原谱对照保留完整。
- **试听和报告对应实际演奏。** 键位预览、适配试听和游戏演奏共用排程。适配报告显示实际演奏音符、按键合并、剪枝和延后。移调推荐也会考虑这些变化。
- **界面与名称统一。** 修复游戏乐器、演奏方案等只读下拉框选择后持续高亮文字的问题。左上角艺术字、迷你播放器和帮助统一为“异环演奏工作台”。

本地音频转谱仍是 Beta。完整便携包包含原有离线模型、CPU 运行库和解码器。密集片段可能需要减少音符，可先用原谱对照和适配试听比较，再调整速度或启用声部。

从 Release 下载 **`NTE-Music-Desk-v2.1.0-Windows-x64.zip`**，关闭旧版，完整解压到新目录并运行“异环演奏工作台.exe”。启动时请求管理员权限，以便向高权限游戏窗口发送模拟按键。取消则不打开主界面，授权后从界面启动的子进程继承权限。个人曲目、方案和设置继续保留。
