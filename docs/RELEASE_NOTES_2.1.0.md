# 异环演奏工作台 v2.1.0

这一版重点改善密集钢琴谱的可演奏性，并让工作台更适合日常使用和录制。

- **密集钢琴谱自动适配。** 遇到按键冲突时，先合并重叠音、重新分组或局部延后，必要时才减少冲突音符。原始 MIDI 保留完整。适配试听、键位预览和游戏演奏共用同一套排程，报告可查看哪些音符被合并、延后或删减。
- **录制时可隐藏迷你播放器。** 在游戏中按 **F6** 即可隐藏或恢复小窗，播放继续进行。顶部的「迷你播放器」也可手动开关小窗。
- **界面更清晰。** 支持 Windows 高 DPI 绘制，主窗口默认以紧凑尺寸打开。顶部只保留「迷你播放器」和「帮助」，左下角「使用引导」改成固定大小的三步便签。修复下拉框选完后文字持续高亮的问题。
- **音频转谱统一入口。** 通过左侧「导入音乐」选择音频即可开始，收起后可在按钮下方查看后台进度或结果。便携包自带钢琴与歌曲的离线模型，解压即可使用。旧转谱工具已移除，过去生成的 MIDI 仍可载入。

下载 **`NTE-Music-Desk-v2.1.0-Windows-x64.zip`**，关闭旧版，完整解压到新目录，再运行「异环演奏工作台.exe」。启动时请求管理员权限，以便向高权限的游戏窗口发送演奏按键。取消则退出，授权后从工作台启动的子进程会继承权限。

转谱仍处于 Beta。密集混音可能有错漏音，游戏内效果也受音域与实际发声限制，建议先试听。
