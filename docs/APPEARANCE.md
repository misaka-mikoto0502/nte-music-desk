# 界面设计记录

2.1.0 的侧栏显示“异环演奏／工作台”两行艺术字，迷你播放器和轻量转谱页也使用中文全称。字标与生成记录见 [字标记录](BRANDING.md)。以下按设计阶段保留记录，2.0.1 的发布范围见 [更新说明](RELEASE_NOTES_2.0.1.md)。

## 2026-11-08 · 完整中文图像字标（2.0.1）

2.0.1 引入两行七字整体艺术字，以透明 PNG 呈现。七个字采用一致的饱满笔画和柔和切角，深绿色为主，少量绿色笔画作强调；两行字的视觉字号接近。运行时等比例缩至 176 px 宽的区域，保持原有侧栏结构和导入入口位置。

## 2026-11-08 · 演奏设置、速度条与报告（2.0.1）

演奏设置分为速度与移调两组，中间以留白和浅色分隔线区分。重置位于标题右侧，自动保存说明附在标题悬停提示。推荐方案紧邻移调，更多参数按需展开。“试奏 20 秒”和“回到起点”从界面移除，定位集中到进度条。

速度条使用细轨道、已选进度与圆形明音头像滑块，提供 0.25×、1×、2× 刻度。支持方向键微调、双击恢复原速及数值输入。界面基础色板保持四种颜色，角色图片保留原色并限定在滑块内，素材来源记录于第三方说明。数值调整改用横向减号／输入／加号；下拉框缩小箭头，移除悬停时的深色整框。

适配报告区分原曲总长、演奏时长及变更时间点。“原曲位置（分:秒）”将 180 秒显示为 03:00.000；导出数据仍使用精确秒数。推荐窗口补充实际排程的最多延后量，并标出当前移调。

## 2026-11-08 · 导入入口与中文标识（设计阶段记录）

侧栏只保留一个导入按钮，同时接受点击选文件和拖入本地曲谱／音频。按钮第二行提示两种操作，底部保留使用引导。文件菜单与 Ctrl+O 使用同一导入流程。

NTE 替换为原创中文“异环”线条艺术字，下方是“演奏工作台”。字形使用原生画布绘制，开放端点与绿色横笔构成标识，显示不依赖额外字体或图片资源。颜色沿用现有色板。

移除“演奏片段”模块，进度条提供开始位置。“原谱对照”置于演奏页乐器和方案卡片右下方，作为辅助操作；从当前进度试听所选声部，与底部适配试听使用相同速度和移调。旧片段方案先备份，再恢复完整时间轴，避免出现没有可见控件的范围限制。

## 2026-11-08 · 控件外观与显示时机

按钮使用统一圆角与留白。绿色填充用于主操作，次级操作使用浅底，悬停或键盘聚焦时出现轮廓，按下时切换为明显的反馈。底部主按钮预留 176 px，次按钮预留 112 px，操作行至少 48 px 高。状态说明区固定为两行，完整内容可悬停查看。

原生下拉框使用圆角浅底和简洁箭头，聚焦时显示绿色轮廓。下拉列表带留白，选中项使用浅底与绿色文字，展开为悬浮层。文本变量、只读／禁用状态、键盘选择和已有方案值沿用 ttk 行为。

| 状态 | 次操作位置 | 主操作位置 |
| --- | --- | --- |
| 曲谱就绪 | 试听 | 开始演奏或从这里继续 |
| 试听准备／播放 | 停止试听 | 开始演奏 |
| 游戏准备／倒计时 | 停止演奏 | 保留位置 |
| 游戏演奏 | 停止演奏 | 暂停 |
| 游戏暂停 | 停止演奏 | 继续演奏 |
| 音频处理中 | 按当前曲谱提供试听 | 禁用并显示音频处理中 |

切换演奏／调整页时，标题、曲目栏和播放区保持固定位置。更多演奏参数与键位预览仅在主动展开时进入调整页的内容区，由该区域滚动承载。引导通过侧栏或帮助菜单打开，提示在悬停于相关控件时出现。

## 2026-11-08 · 模块布局与四种基础色

主窗划为三个固定区域。左侧曲目栏负责导入、选曲与入门帮助。中央工作区以“演奏”和“调整”两个页面切换。底部播放区负责试听、开始、暂停、停止和进度，切换页面时保持原位。

演奏页只保留游戏乐器与演奏方案两个选择。片段、速度、移调和声部集中在调整页，技术统计、适配报告、键位预览和导出归入同一模块。曲目数量不足一屏时隐藏侧栏滚动条。主窗采用纯色背景，引导通过侧栏或帮助菜单打开。

| 基础色 | 用途 |
| --- | --- |
| 白色 `#FFFFFF` | 内容区域和输入控件 |
| 浅灰 `#F3F2ED` | 工作区背景、分隔和悬停区域 |
| 深色 `#293A32` | 文字、边框和次级操作 |
| 绿色 `#326B52` | 主操作、当前选中项和进度 |

共享颜色名称映射到这四种基础色，原生音频设置、声部工作区和迷你播放器共用同一色板。系统窗口装饰由 Windows 绘制。

按钮与下拉框采用统一的柔和圆角，内容面板通过留白分组。默认播放区显示“试听”和绿色“开始演奏”。试听时原位置切换为“停止试听”，游戏演奏时显示“停止演奏”和“暂停／继续演奏”。说明文字附着在相关控件的标签、悬停提示或专门的引导窗口中。

旧版背景浓度和折叠偏好可以正常读取。首次进入新布局显示演奏页，随后记住本布局的页面选择。曲目方案继续按内容与乐器保存。

## 2026-11-08 · 初版易用性预览（历史方案）

以下为本轮初稿，最终布局和颜色以本页上方 2.0.1 记录为准。

首页围绕当前曲目、乐器选择、演奏方案和底部演奏控制组织。新增浅绿入门卡片，提供《小星星》示例与三步引导。使用者可收起卡片，从左下角再次打开引导。

曲谱与音频共用“导入我的音乐”入口。演奏方案采用直观名称，保留原有的方案标识与旧标签兼容。速度、移调、片段、声部、排程、报告和导出收进“更多调整”，展开偏好随个人设置保存。试听与游戏演奏采用两种视觉权重，试奏放在次级操作行。

延续城市背景与墨绿侧栏，使用暖白卡片、浅绿引导区、统一留白和焦点样式。以普通和最小窗口检查主操作可见性，长内容通过正文滚动访问。当前应用版本元数据为 2.0.0，源码标题标为开发预览。

## 1.3.1 历史设计

风格采用暖灰底、墨绿侧栏和少量铜色提示。侧栏作为曲目架，右侧作为演奏台；主要操作保持在底部。减少重复的大号统计卡和流程编号，将时长、音符、音域合并为一条信息栏。

按钮、面板使用不同大小的圆角：主要按钮约 12 px，内容面板约 20 px。基于 Pillow 超采样绘制边缘，按钮仍为 Tk 原生 Button，保留键盘焦点、空格触发、invoke 和禁用行为。树表、输入框与系统菜单继续使用原生交互。这里只更改界面和外观偏好，不改变曲谱或按键调度。

## 1.3.1 背景与隐私（历史记录）

- 旧背景自 2.1.0 起从资源目录移除。原图可从 [2.0.2 标签](https://github.com/misaka-mikoto0502/nte-music-desk/blob/v2.0.2/src/nte_music_desk/assets/city-session.png) 找回。
- 原素材：用户提供素材库中的 `26_10_15_15_54_51.png`，夜间城市持吉他截图。
- 使用内置 imagegen 工具清除灰色相框、底栏、日期、UID 和角落文字；原始截图和 UID 不放入项目。
- 应用运行时对背景降低饱和度并叠加暖灰遮罩，左侧文字区域更淡。透明度只影响背景区，不使窗口文字和控件变透明。
- “外观”菜单提供关闭、淡雅、柔和、清晰四档，默认 .32；选择保存到个人设置文件。缺少图片时回退为纯色背景。
- 游戏角色、场景和截图衍生背景的权利归相应权利人；它不在项目自有 MIT 图标的许可范围内。原图标保持不变。

## 运行与验证

源码界面增加 Pillow 依赖，使用 `python -m pip install -e .` 安装。EXE 已包含依赖，无需用户安装。构建使用 Pillow 13.0.0，并收集其许可证。

检查普通/最小窗口、展开高级设置、多轨、曲库和音频窗口；菜单浓度切换、长标题截断、禁用按钮和样式重建均不能修改演奏方案。原有功能测试继续执行，并对新的冻结包做独立解压自检。
