# 异环演奏工作台 v2.0.1

2026-11-08 · 界面、易用性与演奏设置

本版重点让导入、试听、调整和演奏更容易找到，统一界面风格，并完善移调推荐与适配报告。

## 本版改进

- **更清晰的布局**：左侧曲目栏、中央“演奏／调整”页面、底部固定播放区。播放按钮随任务状态切换，保持位置与尺寸稳定。
- **统一的界面与控件**：四种基础色、完整中文图片字标、圆角按钮和下拉框、横向数值步进。速度条采用明音头像滑块，支持拖动、数值输入、键盘微调和双击恢复原速。
- **一个导入入口**：点击“导入音乐”、拖入文件或 Ctrl+O 均可导入曲谱和音频。内置《小星星》和三步引导方便首次使用。
- **更少的冗余操作**：原谱对照放在演奏页；移除片段输入、试奏 20 秒及回到起点按钮，通过进度条定位和续播。速度、移调、声部与检查工具集中在调整页，更多参数按需展开。
- **更完整的移调建议**：搜索 −36 至 +36 的全部 73 个半音，综合音域、删音、重合、旋律轮廓与实际排程延后，同分优先保持当前移调。应用后仍需试听比较。
- **更清楚的适配报告**：原曲位置以分:秒显示，例如 180 秒显示为 03:00.000；原曲总长、演奏时长和速度分别列出。
- **保留已有方案与位置**：兼容旧名称，变速和重启后继续对应同一原曲位置。旧片段方案先备份，再迁移到完整时间轴；命令行仍支持片段转换。

支持 MIDI／MusicXML、本机音频转谱 Beta、多轨调整、迷你播放器及可选高级引擎。

## 下载与升级

普通用户下载 `NTE-Music-Desk-v2.0.1-Windows-x64.zip`，完整解压到新目录，关闭旧版后运行“异环演奏工作台.exe”，保留 `_internal`。无需安装 Python。首次启动时手动确认 UAC；F7 暂停／继续，F8 停止。

个人设置、曲目架与转换结果位于 `%LOCALAPPDATA%\NteMusicDesk`。旧片段方案的原文件保留为 `.excerpt.backup.json`。重要个人文件建议另行备份。

`NTE-Music-Desk-v2.0.1-Source.zip` 用于开发和构建。两个 ZIP 均附 SHA-256 校验文件。

## 验证与已知边界

124 项 Python 回归、96 组曲谱转换、JavaScript 检查、真实轻量转谱及自动载入、CPU 回退和 Windows 包独立解压自检通过，详情见 [发布验证](VALIDATION_2.0.1.md)。

音频识别继续为 **Beta**。参考短句中，琶音 16 音全部匹配但额外识别 4 音；三和弦虽然输出同为 16 音，仍有 1 处漏音及 1 处多余音。复杂混音、人声、弱音和快速重复音仍需试听校对。移调推荐属于规则建议，不能自动判断音乐听感。

轻量桌面转谱依赖系统 WebView2 Runtime 与 .NET Framework 4.6.2+，高级引擎需另行配置。本轮软件验证不发送游戏按键；游戏音色、并行发声、钢琴音高和悬浮窗操作仍需人工验收。
