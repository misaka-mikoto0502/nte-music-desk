# 异环演奏工作台 v1.4.0

本次更新改为处理用户提供的本地曲谱和音频，移除在线搜曲与下载。原有曲谱导入、两种游戏乐器、多轨适配、合成试听与自动演奏继续保留；旧版下载的本地文件可以手动导入。

- **本地音频工作流**：可选择原曲片段，将已有伴奏 / 纯音乐识别为多轨 MIDI，再交给工作台适配游戏音域。结果文件保留原曲名及选段来源，方便试听核对。
- **主旋律 Beta**：GAME 歌声旋律识别独立试用，不自动替换伴奏结果。首次需安装独立引擎并获取约 46 MB 的官方模型。
- **许可与来源**：转谱前填写素材使用依据，并分别确认模型条款。MuScriptor 和 GAME 权重存在非商业限制；项目代码的 MIT 不替代音乐或模型的许可。原唱自动分离因原权重许可待核实而暂缓开放。
- **使用改进**：修复音频类型在模式切换后显示错误、无效的“分离伴奏”试听入口；固定底部按钮，配置区域可滚动。音频引擎在独立进程中运行，不修改原 Python 环境。

Windows 用户下载 **NTE-Music-Desk-v1.4.0-Windows-x64.zip**，完整解压后双击“异环演奏工作台.exe”。原有曲谱导入与游戏演奏无需安装 Python，便携包不含音频模型或商业歌曲。

音频识别为实验功能，需要试听核对；MuScriptor 真实识别质量尚未完成验收，主旋律继续标为 Beta。本地处理不自动获得改编或公开发布权限。原唱自动分离不是本版可用功能。

本版通过 49 项本地自动测试；独立解压后的启动、资源只读与片段转换另见发布检查。测试没有向游戏发送按键，也不能替代实际游戏发声或模型准确率验收。

本地生成源码包及 SHA-256 文件，源码包不含个人音频、转谱结果、令牌、模型或开发环境。详细配置与许可边界见 AUDIO_TRANSCRIPTION.md、COPYRIGHT_AND_MODELS.md 和 THIRD_PARTY_NOTICES.md。
