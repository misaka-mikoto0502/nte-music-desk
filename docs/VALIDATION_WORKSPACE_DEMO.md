完整 Windows ZIP 为 351,896,119 字节。构建时保留一次启动授权及显眼的权限说明。开发阶段查看了分段页的紧凑布局和候选合成试听；分段与转谱的主要操作位于固定区域，滚动内容不会带走按钮。页面状态及按钮可见性另由 Tk 集成检查覆盖。

运行证据集中在 `.build/validation/workspace-demo/`：全套日志 `full-tests-final.log`、补充用例 `segment-final.log`、转换矩阵 `workflows/report.json`、真实并行 `background/report.json`、最终推理 `frozen-final/*/verification.json`。便携包和对应源代码、SHA-256，以及 `workspace-demo-verification.json` / `workspace-demo-identity.json` 保存在 `releases/v2.1.1/`。一致性校验逐个核对打包模块字节码、资源、展开目录和两份 ZIP。

测试不向游戏发送按键。实际国际服发声、游戏内焦点／悬浮窗交互及 UAC 的人工确认不由这些离线结果代替。合成试听也不代表游戏音色或任意乐曲的听感质量。

社区服务当前仅为本机 Demo；远程 HTTPS 客户端使用兼容 API，公开服务尚未部署。账号、审核、举报、配额、备份和服务运营仍属于后续阶段。旧 2.1.1 包和指定的 2.0.2 录制目录保留。
