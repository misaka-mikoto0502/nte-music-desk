# 1.5 轻量转谱开发测试包

这是开发检查点，不是最终 1.5 发布。原 v1.5.0 包与标签继续保留，不自动推送 GitHub。

新增轻量资源约 1.51 MB；当前便携 ZIP 为 23,713,241 字节，解压应用为 50,983,993 字节。相比上一份 23,029,941 字节 ZIP，下载量约增加 0.683 MB。高级引擎的开发环境和权重没有打入此包。

完整解压后运行“异环演奏工作台.exe”，首次手动确认 UAC。左侧“音频转谱 · Beta”在已有浏览器打开本机页面，先选择有权处理的 15–30 秒音频，填来源说明，再生成并回到工作台试听。无需安装 Python 或登录模型平台。详细流程见 LIGHT_AUDIO.md。

已验证真实浏览器的本机 CPU 推理、MIDI 自动导入及约 39% 时取消。75 项离线测试与独立解压冻结自检通过。音高/起音 F1 在一份钢琴短句为 90.9%，扩展短句仍有明显波动；尚未稳定达到 90–95%，继续 Beta。

用户打开游戏后，统一检查：

1. 从本包启动时只申请一次 UAC，演奏过程中不再申请。
2. 先用内置《小星星》检查吉他钢琴、36 键钢琴及 Shift 黑键，再试和弦与长音。
3. 演奏中按 F7 暂停/继续，按 F8 停止；检查是否释放按键、节奏是否从暂停处继续。
4. 无边框全屏下检查悬浮窗播放、暂停、停止及焦点；独占全屏使用 F7/F8，普通置顶窗不保证覆盖。
5. 再试听并演奏轻量识别结果，区分识别错漏音与游戏音域/多音限制。12–36 音可靠并行数仍需实际听音确认。

本轮软件验证没有发送游戏按键，实际 UAC 和游戏听感还未验收。波形编辑、局部改谱、撤销和更好的试听音色仍为后续规划。
