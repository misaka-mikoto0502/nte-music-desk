# 异环演奏工作台 · 使用说明

主窗采用曲目栏、工作区与固定播放区。左侧负责导入和选曲，中间切换“演奏”和“调整”页面，底部负责试听和游戏演奏。原生界面使用白、浅灰、深色和绿色四种基础色。绿色标记主操作、当前选中项与进度，浅底按钮用于次级操作，悬停或聚焦时显示轮廓。下拉框通过箭头展开浮动列表。

Windows 64 位便携版：完整解压后双击“异环演奏工作台.exe”。无需安装 Python，保留同目录的 `_internal` 文件夹。打开图形应用时通过 Windows UAC 请求管理员权限，需手动确认一次；取消则不打开应用，同次使用中的演奏子进程继承权限。命令行分析、转换与离线自检仍可普通权限运行。

## 开始演奏

1. 从左侧曲目栏选择“小星星 · 示例”，或者点击“导入音乐”选择本地曲谱或音频，也可直接拖入这个按钮。Ctrl+O 打开同一入口。首次可从左下角“使用引导”或帮助菜单打开三步引导。
2. 顶部选择“吉他 · 钢琴模式”或“钢琴 · Shift 黑键”。在游戏里也进入对应的 36 键乐器界面。
3. 点击底部“试听”，从进度条当前位置播放最多 20 秒，体现按键时长、松键间隔与 Shift 分组。试听时该位置变成“停止试听”。
4. 演奏页的“原谱对照”从当前进度试听所选原声部，可与底部“试听”的游戏适配效果比较。默认倒计时 3 秒，可在“更多参数”修改。
5. 试听满意后点击绿色“开始演奏 / 从这里继续”，倒计时期间切回游戏，从当前进度执行至曲末。保持游戏前台并松开键鼠。演奏期间底部切换为停止和暂停／继续；拖动进度条到最左端可返回曲首。

“演奏”页提供“保留丰富声部（推荐）”“突出旋律与低音”“旋律更清楚”和“经典六音和弦”四种方案，并提供原谱对照。“调整”页集中速度、移调和声部，“检查与导出”提供统计、适配报告、键位预览和文件导出。鼠标悬停在相关数值或按钮上可看说明。工具记住页面选择，曲目设置按曲谱和乐器分别保存。

F7 暂停/继续，F8 停止；Esc 也会停止，但可能同时退出游戏演奏界面。切出游戏或游戏关闭会自动停止，并释放程序按住的琴键与 Shift。播放区的“停止演奏”或“停止试听”按钮可结束对应任务。

工具核对游戏窗口标题与 HTGame.exe，不能自动识别当前是否进入了正确乐器界面。

## 迷你播放器与暂停

迷你播放器默认显示在屏幕右上方，拖动标题移动；记住位置和显示偏好。× 仅隐藏小窗，可在“播放器 → 显示迷你播放器”重新打开。主窗最小化不关闭迷你窗；“主窗”按钮会停止当前游戏演奏后返回界面。

小窗提供游戏演奏的开始、暂停/继续和停止，显示曲名及进度。倒计时期间仅可停止，实际演奏开始后可暂停。暂停会释放程序持有的琴键与 Shift 并冻结进度，继续按同一时间轴演奏；尚未结束的长音可能重新触发，游戏已经发出的延音不能被软件静音。电脑合成试听在小窗中可停止，暂不支持试听暂停。

主窗与小窗的进度条可点击或拖动。演奏中拖动时先暂停并松开按键，松开鼠标后恢复拖动前的播放/暂停状态；定位重建尚未结束的音和 Shift 状态。按曲谱内容记住原曲位置，暂停、停止或退出后可续播；变速后仍对应同一原曲时刻，自然播完则下次从头。点击主窗可能因游戏失焦而停止，游戏内定位建议使用小窗；未放宽前台检查。

小窗保持置顶并采用不激活窗口的鼠标处理。鼠标交互推荐无边框全屏；独占全屏不能保证覆盖显示，可用 F7 暂停/继续、F8 停止。切换到其他程序仍停止，不放宽游戏前台检查。不需要向游戏注入覆盖层。新增 UAC 和实际游戏中的点击效果需使用者实机确认。

## 本地导入

v1.4.0不提供在线搜索、音乐下载或曲目搜索快捷入口。请选择自己的 MIDI / MusicXML 曲谱，或通过音频转谱处理自有、已获必要授权的录音。文件位于本机、可试听或可免费下载，都不等于取得转谱、改编或公开发布许可。

旧版的 downloaded_midis 与 .source.json 不删除；从“导入曲谱”或左侧拖入区载入原文件。工具可读取旧来源记录中的曲名，不再访问原下载网站。侧栏只保留曲目架，不再显示“最近打开”。内置《小星星》为自行编码的功能示例。

## 导入格式与转换

| 文件 | 本版支持 | 方式 |
|---|---|---|
| .mid / .midi | 是 | 标准 MIDI 0/1 |
| .kar | 是 | 读取其中的 MIDI 音符，不显示歌词 |
| .rmi | 是 | 读取 RIFF MIDI 容器中的音符 |
| .musicxml / .xml | 是 | score-partwise MusicXML |
| .mxl | 是 | 压缩 MusicXML，按容器声明读取主曲谱 |
| .mscz / .mscx、Sibelius、Finale 工程 | 需先导出 | 用原制谱软件导出 MusicXML/MXL 或 MIDI |
| MP3 / WAV 等录音 | 可选音频转谱 | 左侧轻量 Beta 默认在独立桌面窗口中本机 CPU 识别；高级处理另装引擎，均非无损转换 |
| PDF / 乐谱图片 | 不能直接导入 | 先用乐谱识别 OMR 软件校对并导出 MusicXML |

MusicXML 导入保留显式音高、时值、休止、声部、和弦、连音和速度变化，支持普通反复及编号房子。无时值装饰音和颤音记号不展开；D.C./D.S./Coda/Fine 跳转会显示警告。小节内反复、嵌套反复、不一致的声部反复、微分音及 score-timewise 暂不支持，请先在制谱软件中展开或改用 MIDI。只含第一页的片段若缺少反复终点，也会提示检查曲谱。文件最大 16 MB，MusicXML 展开主文件最大 8 MB。

导入后可直接试听和演奏，也可点击底部“另存 MIDI”或菜单“文件 → 另存原曲为 MIDI”，把原曲全部声部转成标准 MIDI。此导出不应用当前游戏演奏的选轨、变速、移调或简化；保留音符的秒级时刻，使用统一 120 BPM 网格保存，不保留原始速度标记、排版、歌词或踏板。JSON“导出曲谱”则保存当前游戏演奏设置下的结果。

另存 MIDI 会保留乐器程序并重排通道，鼓组使用通道 10；单端口最多支持 15 种有音高乐器，超过时提示先在制谱软件合并音色，不会静默改成钢琴。

音频识别可能产生错音或漏音。左侧“音频转谱 · Beta”打开独立的本机转谱窗口（浏览器兼容入口在文件菜单），新增资源约 2.33 MB，无需 Python、GPU 或模型账号，适合清晰单乐器；详见 LIGHT_AUDIO.md。单次最多 3 分钟，可取消，显示预计剩余时间；完成后自动下载、在工作台保留副本并导入，不会开始游戏演奏。网页与桌面左侧小型导入区支持拖入文件。默认均衡模式；多保留弱音可能增加杂音，轻微起音对齐最多提前 24 毫秒，分解和弦建议关闭。对齐前 MIDI 另行保存。

同一次模型推理还会保留另一档识别结果；完成后可点击“使用弱音版 / 使用均衡版”免重算切换，自动载入工作台并发起下载。初选旋律时保留旋律版与弱音版。两版各自保存，不互相覆盖；弱音版可能补出弱声部，也可能增加误判。新识别 MIDI 统一力度 96，未估计原曲真实动态；已有的 MIDI 文件保持原力度。

“文件 → 高级音频处理（独立引擎）”保留独立安装流程：UMX-HQ 可单独分离人声与伴奏，无需账号；MuScriptor 将伴奏识别为多轨 MIDI，首次需要完整 Python、模型许可授权和 Hugging Face 登录。GAME 主旋律保持 Beta，可单独运行或与分离后的伴奏一起识别。详见高级窗口的“配置说明”。核心演奏和轻量转谱无需这些依赖。

考虑音乐版权风险，工具不提供搜曲或下载，请选择你有权处理的本地音频，文件不会上传。转谱前“试听选段”只解码最多 30 秒，无需加载模型。结果中的“对照试听”支持同位置切换原音频、伴奏/人声和曲谱合成音，支持定位、暂停、循环；最多比较选段前 30 秒。曲谱合成音用于核对音高与节奏。古典钢琴仍优先使用现成 MIDI 或 MusicXML。

## 乐器与和弦

同一份 MIDI 切换乐器时，工具会自动重新转换键位与音域，无需额外音频或转换软件。

- 吉他钢琴模式：E3–D#6，三排独立半音键；支持各演奏模式。
- 钢琴：白键低音 Z X C V B N M、中音 A S D F G H J、高音 Q W E R T Y U；黑键为对应白键加左 Shift，暂按 C3–B5 编排。界面没有绝对音高，必要时用移调 ±12 校准八度。Ctrl 降半音在游戏中可用，但程序统一使用 Shift 表达黑键。
- 旋律版在相隔不超过 25 毫秒的一组音中只保留最高音；它是简化规则，不保证自动找到所有曲目的主旋律。
- “经典六音和弦”最多保留同组 6 音，兼容已有方案。新曲默认“保留丰富声部”，每组默认 12 音，高级设置可设 2–36，保留独立起音，优先声部整体移动八度。“突出旋律与低音”优先保留骨干声部，最多 6 音。“旋律更清楚”采用旧单旋律规则，每组取最高音。
- 点击轨表第一列圆点启用或静音，点选一行作为当前试听轨。打开“多轨工作区”查看原乐器、原轨/通道、角色、音域和音符总览，设置独奏及主旋律/低音/伴奏角色。鼓组不映射琴键；初始角色为规则猜测，可以修改。
- 钢琴全白键或全黑键和弦成组按下；混合黑白键先白后黑，约错开 55 毫秒。这是滚奏近似，音色、延音和多音上限取决于游戏。过密的曲谱会提示降低速度或减少音轨。

## 常用设置

速度 1.0 是原速，0.8 更慢，1.2 更快；支持 0.25–2。拖动明音头像调整速度，方向键每次微调 0.01，双击滑块恢复原速，也可直接填写数值。移调单位为半音，±12 为一个八度，可直接输入或使用横向减号、加号。修改参数会自动更新曲谱。“更多参数”可调整倒计时、每音按键上限、和弦音数和超出音域的处理方式。

“近同时起音对齐（原曲 24ms）”将稍微错开的和弦起音对齐，默认关闭。钢琴只对齐相同 Shift 状态，混合黑白键仍需分组；重复同音不合并，单旋律模式不启用。分解和弦与装饰音建议保持关闭。只改变演奏、时序试听及报告，不修改原 MIDI。

通过进度条点击或拖动选择开始位置，位置会自动记忆。演奏和试听从当前位置开始；原曲中的停顿继续保留。变速后仍对应同一个原曲时刻。

“单独试听当前轨”播放最后点选的一条有音高声部，包括已静音声部，不改变演奏选轨；演奏页的“原谱对照”播放当前启用声部。两者从进度条当前位置开始，保留原始声部与音域，不做游戏和弦简化或折回，但应用速度与移调。使用合成音色，每次最多 20 秒，过密原谱可减少音轨。

“推荐移调方案”在后台比较 −36 至 +36 的全部 73 个半音，展示最多三个符合当前调度限制的方案。综合丢音、折回、重合、旋律轮廓变化、钢琴混合分组和实际排程延后排序，同分时优先保持当前移调。它没有识别调性、真实主旋律、和声或音色，规则权重也不代表听感质量。应用后再分别试听原谱和适配效果。钢琴绝对音高仍需听感校准。

本曲设置在成功转换与调度检查后自动保存，钢琴和吉他分别记忆选轨、模式、速度、移调、音域策略、起音对齐和按键上限。旧方案若设置过片段，会先在方案目录保留 `.excerpt.backup.json`，再恢复完整时间轴；已有续播位置继续使用，没有续播记录时沿用旧片段起点。命令行仍支持按起止时间转换片段。

倒计时按应用全局记忆，不随切歌恢复旧值。同一文件改名或移动后仍可恢复；内容变化视为新曲谱。“恢复默认”重置当前曲目、当前乐器的方案及默认倒计时。曲目架记忆导入文件的路径，移动文件后需要重新选择。

“八度折回”保留音名但会改变旋律的上下走势，也可选择丢弃越界音或报错。程序保留音符起点与速度变化，不将力度、延音踏板、弯音、录音或原乐器音色转换成操作。默认每音最多按住 300 毫秒，游戏长音触发后自然延音。

展开“键位预览”可看前 8 音，“曲谱明细”列出完整键位。“导出曲谱”保存当前转换后的 JSON；演奏无需事先手动导出。

“适配报告”列出简化、折回、丢弃和同音重合的位置。“原曲位置”按分:秒显示，例如 03:00.000 表示原曲第 3 分钟的变更时间点；表头另外显示原曲总长、本次演奏时长和速度。导出的 JSON 继续保留精确秒数。一个音可能既折回又被合并，因此各变更次数不应直接相加作为音符总数。明细最多记录 2000 条，计数为完整统计；报告另包含最多 2000 个计划演奏音符。计划和按键发送完成都不等于游戏已成功发声。支持游戏演奏暂停/继续，暂不包含 A/B 自动循环。

报告还显示实际排程的并行键峰值和最大起音偏差。和弦音数是每个起音组保留上限，长音重叠可能使并行键更多；不等于游戏已支持该多音数。原曲声部的整体八度调整保存在 JSON 报告 voice_octaves 字段。

## 数据与快捷键

默认数据目录：%LOCALAPPDATA%\NteMusicDesk。菜单“文件 → 打开数据目录”可直接查看。

- midi_ui_settings.json：上次曲目、曲目架引用、播放位置、全局倒计时及界面偏好。
- light-transcriptions：轻量转谱的最终 MIDI、另一档识别结果、候选谱和处理记录；属于个人数据，不要整体上传。
- arrangements：按曲谱 SHA-256 与乐器保存的演奏方案；没有曲谱原件或个人绝对路径。
- downloaded_midis：旧版遗留的本地曲谱及来源记录，新版不新增下载。
- catalog_cache：旧版遗留缓存，新版不读取或更新。
- runs：各次演奏曲谱、进度和结果；completed 只表示发送完成。
- logs：异常日志（发生启动或操作错误时生成）。
- audio-engine、audio-engine.json：可选引擎及路径/模型配置；不保存登录令牌。
- transcriptions：每次解码选段、MIDI、来源与使用依据、模型记录和日志尾部；含私人内容，不要整体上传。

升级时用新版软件目录替换旧版，个人数据不会随软件覆盖。备份上述数据目录即可保留已下载曲目与设置。导入的外部文件仍引用原文件，请自行保留。

Ctrl+O 导入，Ctrl+Enter 从当前进度演奏，F7 暂停/继续，F8 停止。前两个在工具窗口内使用，演奏时 F7/F8 在游戏中也有效。

音频拖入默认打开独立桌面窗口，复用系统 WebView2 与 .NET Framework，不启动浏览器。转谱页及小模型约 2.33 MB，加上窗口宿主约 0.85 MB，总增量约 3.18 MB。兼容浏览器模式需从文件菜单主动选择。

转谱结果页可比较候选谱与对齐前 MIDI。候选包含误判，数量差额不代表漏掉的真实音；在工作台选择单旋律方案也会减少和弦。轻量、高级处理与游戏演奏不能同时启动，正在处理时仍可点击轻量按钮唤回其窗口。
